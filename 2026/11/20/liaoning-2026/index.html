K.显卡

有 nnn 个显卡和 mmm 个人，你需要把 mmm 张显卡分给 nnn 个账号，然后你使用显卡数量最少的一个账号，求你可以使用的最多的显卡数量。

solution

签到题，根据抽屉原理可知答案是 n/mn/mn/m 。

J.数字谜题

你和对手各有 9×n9\times n9×n 张手牌，其中数字 111 到 999 各有 nnn 张。每次出牌比较双方数字大小，数字大的一方获得自己打出的数字对应的积分，每个数字的积分等于对应手势伸出的手指数，如 111 ~ 555 对应积分 111 至555 ，数字 666 对应积分 222 ，等等。

现在你知道对手的出牌顺序，求你能够获得的最高总分。

solution

还是签到题，对于每一套 111 ~ 999 的牌，你可以让 999 赢 888，888 赢 777 ，以此类推，最后 111 输给 999 ，可获得 212121 分，答案即为 n×21n\times 21n×21 。

D.可爱的质数

给定一个长为 nnn 的数组 a1,a2,…,ana_1,a_2,\dots ,a_na1​,a2​,…,an​ 。你可以进行任意次操作，每次操作选择一个下标 iii 和一个质数 ppp ，要求 p<aip<a_ip<ai​ ，然后把 aia_iai​ 变成 aia_iai​ mod ppp 。

求出能让数组所有元素变成 000 的最小操作次数，或者若做不到则输出 −1-1−1 。

n≤5×105n\le 5 \times 10^5n≤5×105 ，$ 1 \le a_i \le 10^7$

solution

观察到对于一个合数，可以直接选择它的一个质因数，一步把它变成 000 。

对于一个质数，不难发现它不可能一步变成 000 ，那用两步能不能呢？

手玩一下发现 2,3,5,72,3,5,72,3,5,7 是没法变成 000 的，遇到它们应输出 −1-1−1 ；从 111111 开始，对于质数 ppp ，存在一个质数 qqq 满足 p/2≤q≤p−4p/2 \le q \le p-4p/2≤q≤p−4 ，然后可以将 ppp 变为 p−qp-qp−q ，这是一个大于 444 的偶数，所以接下来再选择 222 即可。

接下来要特判 000 和 111 ，如果是 000 则不用处理，是 111 则无法处理输出 −1-1−1 。

使用线性筛预处理后依次检验数组每个元素即可。

时间复杂度 O(V+n)O(V+n)O(V+n) ，其中 V=107V=10^7V=107 为值域。

L.情绪波动计划

对于每组测试数据,给定两个整数 nnn、kkk 和一个长度为 nnn 的数组 aaa ，你需要重新排列数组 aaa ，让数组中“情绪波动”的次数恰好为 kkk 次，其中“情绪波动”是指数组相邻两项为一奇一偶；或者判断无法构造。

solution

这道题赛时是队友给出的构造思路。首先注意到只需要关心元素的奇偶性，然后判断能够构造出的“情绪波动”的次数范围：设奇数出现次数为 xxx ，偶数出现次数为 yyy ，则上界为 2×min(x,y)−[x==y]2\times min(x,y)-[x==y]2×min(x,y)−[x==y] ，下界为 [x>0 and y>0][x>0 \text{ and } y>0][x>0 and y>0]。

在判断能构造后，首先交错摆好 k+1k+1k+1 个奇数和偶数，然后把剩下的奇数放在第一个奇数的后边，剩下的偶数放在第一个偶数的后边即可。

B.VP选手的最优解题方案

你现在有 nnn 道题目和 ttt 分钟时间，每道题目 iii 都有 aia_iai​ 的思考时间和 cic_ici​ 的编码时间。在这道题中你必须顺序看题，每道题都需要思考完，即花费 aia_iai​ 的时间，然后你需要决定是否再花 cic_ici​ 的时间去编码解决它。

现在需要求出能编码出的题目的最多数量。

1≤n≤2×1051\le n\le 2\times 10^51≤n≤2×105 , 1≤ai,ci≤1091\le a_i,c_i\le 10^91≤ai​,ci​≤109

solution

看到这个题目第一感很难不是背包，但细想发现不可行，因为 aia_iai​ 和 cic_ici​ 的值域很大。

思考如果考虑到了第 iii 题，那么显然应该贪心地选取 [1,i][1,i][1,i] 里编码时间最短的题目，此时发现如果一道题在此时没有被选到，那么它在后边就更不可能被选到了（因为可用时间变短并且后边可能会有编码时间更短的题目）。

由此想到使用大根堆维护考虑到第 iii 题时当前所有被选中的题目，后续题目加入大根堆后若发现总编码时长超过剩余时间，则不断弹出堆顶直到总编码时长小于等于剩余时间。

时间复杂度 O(nlog⁡n)O(n\log n)O(nlogn)

F.咏人不知

（题目内定义较多，所以选择复制原题面）

在 7sRef 世界的法则中，音乐使用七个音级 1,2,…,71,2,\dots,71,2,…,7。对整数 xxx 定义

[x]7=((x−1) mod 7)+1,[x]_7 = ((x-1) \bmod 7) + 1, [x]7​=((x−1)mod7)+1,

D(x,y)=min⁡(∣x−y∣, 7−∣x−y∣).D(x,y)=\min\bigl(|x-y|,\ 7-|x-y|\bigr). D(x,y)=min(∣x−y∣, 7−∣x−y∣).

一个和弦由一个整数 c∈[1,7]c\in[1,7]c∈[1,7] 表示，共有三种转位 t∈{0,1,2}t\in\{0,1,2\}t∈{0,1,2}。和弦 ccc 采用转位 ttt 时的最低音为

B(c,t)=[c+2t]7,B(c,t)=[c+2t]_7, B(c,t)=[c+2t]7​,

即最低音可取 c, [c+2]7, [c+4]7c,\ [c+2]_7,\ [c+4]_7c, [c+2]7​, [c+4]7​ 之一。

同一个和弦可以通过改变最低音得到不同的转位；连接相邻和弦时，合适的转位能使最低声部移动更平滑。

若十进制正整数 xxx 的每一位都属于 1∼71\sim 71∼7，则称 xxx 为合法乐谱编号。设 xxx 的十进制表示为 a1a2⋯ana_1a_2\cdots a_na1​a2​⋯an​，将其看作和弦序列 a1→a2→⋯→ana_1\to a_2\to\cdots\to a_na1​→a2​→⋯→an​。

对于某个乐谱，Liz 希望为每个和弦选择合适的转位，使整段进行中最低音的音级距离之和尽可能小。她想知道，给定一个乐谱编号，这种最小代价是多少。

形式化地，为每个和弦 aia_iai​ 独立选择转位 ti∈{0,1,2}t_i\in\{0,1,2\}ti​∈{0,1,2}，则该进行的总代价为

∑i=1n−1D(B(ai,ti), B(ai+1,ti+1)).\sum_{i=1}^{n-1} D\bigl(B(a_i,t_i),\ B(a_{i+1},t_{i+1})\bigr). i=1∑n−1​D(B(ai​,ti​), B(ai+1​,ti+1​)).

令 H(x)H(x)H(x) 为所有转位方案中总代价的最小值（xxx 只有一位时 H(x)=0H(x)=0H(x)=0）。

1≤∣x∣≤2×1051\le |x|\le 2\times 10^51≤∣x∣≤2×105。

solution

这次真是dp，对于每个 $1\le i \le n $ ，考虑第 iii 位和第 i−1i-1i−1 位分别使用的转位即可。

A.海鸥传说

有 nnn 只海鸥和一个无限食物堆在一个行列编号均为整数的无限二维网格中和一个初始为空的操作栈，你需要指挥所有在场的海鸥前进或者撤退。

前进：代价为 111 。效果为指挥所有在场的海鸥向某个方向移动任意格，然后将本次操作的（方向，距离）压入操作栈。

撤退：代价为 000 ，且执行时操作栈非空。效果为弹出栈顶的操作，然后指挥所有在场的海鸥按照弹出的（方向，距离）沿该方向的相反方向移动该距离。

每次操作结束后，如果有海鸥位于食物格，那么它会吃掉一份食物后飞离网格，注意海鸥飞行过程中若经过食物格不会吃掉食物。

你需要求出让所有海鸥吃到食物的最小总代价。

1≤n≤5×1051\le n \le5\times 10^51≤n≤5×105 ，1≤ri,ci≤5×1051\le r_i,c_i \le5\times 10^51≤ri​,ci​≤5×105

solution

赛时写这道题的时候出现了严重的思路出错，导致浪费了将近两个小时的时间，这两个小时也导致我们从银牌区掉到了铜牌区。

首先，海鸥的整体移动，等价于食物堆单体反向移动，所以可以从操作一群海鸥改成操作一个食物堆。

然后先只关注任意一只海鸥，它想吃到食物至少要走 111 步，且最多要走 222 步，问题的焦点自然到了如何让更多的海鸥只走一步而不是走两步。

由于“撤退”这一操作的存在，如果食物堆“来过”了位置(x,y)(x,y)(x,y) ，那么它将可以以 111 点代价到达横坐标为 xxx 和纵坐标为 yyy 的所有点。

图中红色为食物堆“前进”路线，绿色为食物堆“撤退”路线。

理解了这个事情后，问题转化成了求海鸥和食物堆共 n+1n+1n+1 个点的连通块数量 cntcntcnt 。如果只有一个连通块，则答案为 nnn ；每多出一个连通块，就需要多花 111 步去连接它们。

所以最后的总代价就是 n+cnt−1n+cnt-1n+cnt−1。

M.毛毛虫想吃麦香鱼

通信题

first：你会拿到一棵层数不超过 333 的树，这棵树采用BFS遍历得到的序列为 1,2,…,n1,2,\dots ,n1,2,…,n ，这棵树用一个长度为 n−1n-1n−1 的序列 ppp 给出，其中 pip_ipi​ 表示节点 i+1i+1i+1 的父节点为 pip_ipi​ 。

你需要输出一个长度不超过 n−1n-1n−1，元素在 [1,n−1][1,n-1][1,n−1] 内且无重复元素的非空整数序列，然后评测机会打乱你传出的序列的顺序。

second：你会收到你在第一次运行时传出的序列，并且你不知道这组测试数据对应的树的节点数，你需要通过这个序列还原出它对应的树。注意测试数据的顺序也会被打乱，但是一定能对应第一次运行时你传出的某一个序列。

1≤n≤1051\le n\le 10^51≤n≤105

solution

难点在于评测机会打乱第一次运行时传出的序列的顺序，以及传出序列的元素值域问题以及不能重复。

通信思路并不只有一种，但都要聚焦于如何解决上边两个难点。对于值域和不重复问题，想到使用前缀和记录第二层每个节点的子树节点数量，这样当跑完第二层所有节点时，序列的长度恰好能对应第二层的节点数量，且最后一个值恰好是 n−1n-1n−1 ，不会存在超值域的问题，而由于前缀和的性质，每次访问下一个节点，前缀和至少会增加 111 （也就是该节点在第三层没有子节点），所以也不会存在值重复的问题；对于打乱顺序，只需要在接收序列时将其排序，即可还原传出时的序列。

在还原树时，将前缀和作差分还原为第二层每一个节点的子树大小，然后就可以还原整棵树。

由于需要排序，所以时间复杂度为 O(nlog⁡n)O(n\log n)O(nlogn)

除此之外，也可以改造初始的父节点序列（官方题解思路二）；也可以在遍历第二层节点时，若它有子节点，则记录编号最大的子节点编号，否则就记录该节点本身编号，此时传出的序列长度 kkk 同样对应第二层节点数量。恢复时，将收到的序列分为大于 kkk 和小于等于 kkk 两个部分分别排序，然后遍历节点 [2,k][2,k][2,k] ，判断它有没有子节点（来自群友的思路）。
